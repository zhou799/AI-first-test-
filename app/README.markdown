#  AI 私厨管家

> 上传食材图片，获取个性化食谱推荐

![AI 私厨管家](static/preview.png)

##  功能特性

- 📸 **智能食材识别**：支持上传食材照片或输入食材清单，自动识别并评估食材新鲜度与可用量
- 🔍 **智能食谱检索**：基于可用食材清单，通过 Tavily 搜索引擎智能检索可行菜谱
- 📊 **多维度评分排序**：从营养价值和制作难度两个维度对食谱进行量化打分和排序
- 📝 **结构化方案输出**：生成包含食谱信息、得分、推荐理由和参考图片的专属烹饪建议
- 💬 **流式对话体验**：基于 Server-Sent Events (SSE) 实现流畅的实时对话体验
- 🧠 **会话记忆管理**：支持历史消息存储与检索，保留多轮对话上下文
- ☁️ **阿里云 OSS 集成**：支持图片上传至阿里云 OSS 存储服务

## ️ 技术栈

| 技术 | 说明 |
|------|------|
| **后端框架** | FastAPI + Uvicorn |
| **AI 框架** | LangChain + LangGraph |
| **大语言模型** | 通义千问 qwen3.6-plus (DashScope) |
| **搜索引擎** | Tavily Search API |
| **前端** | Next.js (预编译静态资源) |
| **数据库** | SQLite (会话记忆) |
| **对象存储** | 阿里云 OSS |
| **部署方式** | 本地开发服务器 |
